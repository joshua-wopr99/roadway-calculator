# Roadway Quantity Calculator

A free, installable, offline web app for field quantities: square feet, square yards, cubic feet and cubic yards for rectangles, trapezoids, circles, triangles (base & height or 3 sides) and triangles with a curved edge.

- Thickness in inches or feet, optional waste %, ticket notes, CSV export.
- Works offline after the first visit; items are saved on the device.
- Install: open the site in Safari (iPhone) → Share → Add to Home Screen, or in Chrome (Android) → menu → Install app.

Personal tool; not an official product of any agency.
